# Fcam pro — 設計概要と実装状況（v2.1.0）

## v2.1.0 の変更点（ズームUI・起動時1倍保証・バックグラウンド録画の安全性）

- **ズームUI表示**: 操作パネル上部に現在のズーム倍率ピルを追加（`ZoomPill`）。ズーム対応レンズ（maxZoom > 1）のときのみ表示。ズーム中は強調色＋太字、タップで 1.0x にリセット（UI 状態と `cameraControl.setZoomRatio(1f)` の両方）。日英完全対応（`zoom_ratio` / `cd_zoom_reset` を `values/` と `values-ja/` に追加）。
- **起動時ズーム初期化の保証**: bind 成功後に `zoomRatio = 1f`＋`maxZoomRatio` 更新＋`setZoomRatio(1f)` を明示実行。従来はローカル状態のみ 1f に戻しており、`ProcessCameraProvider` が同一 `Camera` インスタンスを返す場合にレンズ側ズームが残留する論理ミスがあった（UI は 1.0x 表示なのに画角がズームされたまま）。ピンチ上限は bind 直後の `zoomState.maxZoomRatio` を保持し、ジェスチャ時は `ZoomRatios.next()`（単体テスト済み）でクランプ。
- **バックグラウンド録画の安全性**:
  - 連続タップの二重起動ガード（`startPending`＋`removeCallbacksAndMessages`）。従来は 350ms 以内の 2 回目の start が 2 つ目の bind をキューし、`recording` を上書きして 1 つ目の `Recording` をリークした。
  - FGS タイプを用途別に（起動時は CAMERA のみ、音声あり録画時のみ CAMERA|MICROPHONE）。従来は常時 MIC 付きで、音声なし設定・マイク権限なしの端末では Android 14+ で起動失敗した。
  - 使用中のレンズ ID と画面回転を引き継ぎ（`EXTRA_CAMERA_ID` / `EXTRA_TARGET_ROTATION`、対応不可時は従来の前面/背面既定にフォールバック）。従来は望遠・マクロ選択中も広角既定に戻っていた。
  - 通知 largeIcon をキャッシュ（毎秒 `decodeResource` していたメモリ churn を解消）。`ExperimentalCamera2Interop` の OptIn をサービスクラスに付与（lint エラー解消）。
- **録画中の誤操作防止**: BG 録画中はシャッター・レンズ切替を無効化（`camera == null` のため無反応だったタップに明示の disabled 表示）。外部キャプチャバーも同様。`capturePhoto` / `toggleRecording` に `bgRunning` ガードを追加。
- **表記統一**: OTHERS の「Bg record / 背面録画」を「BG record / BG録画」に（「背面」はリアカメラと紛らわしいため）。
- 破壊的変更なし。versionCode 5 / versionName 2.1.0。

## v2.0.0 の変更点（操作パネルの再設計）

3 つのレイアウトを画面サイズ・向きで自動選択（`smallestScreenWidthDp` と `orientation`）:
- **PHONE_PORTRAIT**（<600dp・縦）: 従来のスマホ用の縦積み UI。上部にアイコン行、下部に操作。
- **LARGE_PORTRAIT**（≥600dp・縦）: 画面**左**に浮くパネル。アイコン群は 2 列（二段）、PHOTO/VIDEO/OTHERS は縦タブ。パネルの位置を「上／中央／下」に寄せられ、影（スクリム）はパネルの内容がある範囲だけ（`wrapContentHeight`）。OTHERS は 2 アイコン/行で段が増える。
- **SIDE**（横向き全般）: 画面**右**のサイドバー（全高スクロール）。

共通:
- パネルは下部のボタンで開閉できる（`AppSettings.panelCollapsed` に永続）。閉じると、フロント/バック切替＋シャッター＋「開く」ボタン＋バッテリー残量だけの小さなクラスタが残り、ドラッグで移動可能（画面外に出ないようクランプ）。撮影モードは保持。
- **マニュアル設定を開くボタン（Tune/AutoMode）は PHOTO/VIDEO のときだけ表示。** OTHERS に切り替えた時点で `isManualMode=false`（`CameraViewModel.setMode`）。
- **フロント/バック切替はシャッターボタンの横**（全レイアウト）。上部アイコン行からは撤去。
- **設定アイコンは常時表示**（上部アイコン行の末尾）。
- レンズ切替（超広角/広角/望遠/マクロ/前面）は、対応レンズが 2 つ以上あれば丸ボタンの行として**常時表示**（録画中は無効）。ポップアップは廃止。
- マニュアル撮影パネルから**シャッター音量スライダーを撤去**（シャッター音は設定画面のトグルのみ）。
- 操作パネルの下部に**最新の撮影サムネイル**（実画像/動画フレームを 160px で読込。無ければアイコン）。タップで標準ギャラリーへ。
- バッテリー残量: `ACTION_BATTERY_CHANGED` を `RECEIVER_NOT_EXPORTED` で購読。パネルを閉じたときはシャッターの下に表示。
- ランチャーアイコンを新しい 256px 画像から再生成（全 density、square + round）。

versionCode 4 / versionName 2.0.0。

## v1.0.2 の変更点（安定性・確実性・ドライバ認識・メモリ安全性・UI 完全性の精査）
- **ドライバ認識 / ANR**: カメラ列挙 `detectLenses` をメインスレッドから `Dispatchers.Default` へ。ViewModel 生成時に camera HAL 初期化でメインスレッドが止まらない。`noCameraAvailable` を `StateFlow` 化し、検出完了時に UI へ反映。
- **UI 完全性 / 安定性**: 画面回転で Activity を再生成しない（`android:configChanges`）。プレビュー中断・ローカル状態喪失・黒画面フラッシュを防止。回転時の写真/動画の向きは `DisplayManager.DisplayListener` で `imageCapture/videoCapture.targetRotation` を更新して維持。
- **メモリ安全性**: 写真↔動画モード切替時に旧 `ImageCapture` 参照を null 化、`ImageAnalysis` と ML Kit `BarcodeScanner` を確実に `release()`。QR 解析は専用の単一スレッド `Executor` で実行し、画面破棄時に `shutdown()`。
- **動作の確実性**: ピンチズーム上限を CameraX の `cameraInfo.zoomState.maxZoomRatio` から取得（Camera2 のデジタルズーム最大値ではない）。ズーム比 1.0 のパンジェスチャは無視。
- セルフタイマー中にシャッターを再タップでカウントダウンをキャンセル可能。タイマー `Job` は画面破棄時にキャンセル。
- フォーカスレティクルを `onSizeChanged` で得たプレビュー領域内にクランプ（端タップで枠がはみ出さない）。
- ギャラリーボタンの「最後の撮影」を ViewModel 保持 → 設定往復後も維持。外部 `ACTION_IMAGE_CAPTURE`（`EXTRA_OUTPUT` なし）の返却サムネイルを 1024px 以下へダウンサンプル（`TransactionTooLargeException` 回避）。
- `MainActivity.onNewIntent` 対応 — 起動中に他アプリから `IMAGE_CAPTURE`/`VIDEO_CAPTURE` が来ても取りこぼさない。
- `BackgroundCameraService`: `onCreate` で `running` フラグをリセット（前インスタンス異常終了からの復帰）、`onDestroy` で保留中の Handler コールバックを除去。
- versionCode 3 / versionName 1.0.2。

本ファイルは Fcam pro の設計概要と、各機能の実装状況・既知の制約をまとめた開発向けドキュメントである。
公開用の説明は README.md、次回開発者向けの保守メモは common-rules-document リポジトリの fcam-pro.md を参照。

## 1. アーキテクチャ

- Kotlin 2.2 + Jetpack Compose（Material 3）+ Navigation-Compose
- CameraX 1.5（core / camera2 / lifecycle / view / video）+ Camera2 interop（マニュアル CaptureRequest）
- Room 2.7（撮影プロファイル。破壊的マイグレーション fallback でアップデート時クラッシュを回避）
- ML Kit barcode（QR 検出）
- AndroidX AppCompat の per-app locale（アプリ内言語切替）
- LifecycleService + フォアグラウンドサービス（バックグラウンド録画）
- compileSdk 36 / minSdk 24 / targetSdk 36。追加 API は全て SDK_INT でガード。
- パッケージ: com.oriyu90.fcampro / applicationId 同じ / versionCode 5 / versionName 2.1.0

## 2. 実装済み機能

| 機能 | 実装 |
|---|---|
| 写真・動画撮影 | PHOTO / VIDEO タブ。MediaStore へ保存（Pictures/Movies の Fcam pro フォルダ） |
| アスペクト比 | 4:3 / 16:9 を ResolutionSelector + AspectRatioStrategy で切替 |
| フラッシュ | AUTO / ON / OFF |
| セルフタイマー | 0 / 3 / 10 秒（設定で既定値変更可） |
| フロント/リア切替 | LENS_FACING で切替、対応レンズへ自動遷移 |
| マルチレンズ | 超広角/広角/望遠/マクロ/前面。CameraSelector の CameraFilter で実 cameraId を選択。非対応時は当該向きの既定カメラへフォールバック |
| マニュアル制御 | ISO / シャッター速度 / フォーカス距離 / WB。各スライダーは選択カメラの CameraCharacteristics の range にクランプ。MANUAL_SENSOR 非対応カメラではマニュアルボタンを無効化 |
| AE/AF ロック | CONTROL_AE_LOCK。マニュアル露出時は CONTROL_AE_MODE_OFF |
| タップ AF / ピンチズーム | previewView のジェスチャ → startFocusAndMetering / setZoomRatio。ロック中は無効 |
| プロファイル | 保存・改名・削除・再適用（Room） |
| QR 検出 | ImageAnalysis + ML Kit。1.5 秒デバウンス。URL は「開く」、それ以外はクリップボードにコピー |
| タイムラプス | 間隔 1/3/5/10 秒（設定）。連続 3 回失敗で自動停止。OTHERS 離脱・画面破棄で停止 |
| バックグラウンド録画 | BackgroundCameraService（LifecycleService）。通知の STOP で停止。起動中は Activity 側カメラを unbind して排他制御 |
| OS カメラ連携 | IMAGE_CAPTURE / VIDEO_CAPTURE / STILL_IMAGE_CAMERA を処理。EXTRA_OUTPUT があれば静止画をそのストリームへ書き込み、無ければサムネイルを data extra で返す。動画は MediaStore へ録画し content URI を結果で返す |
| i18n | 英語（既定）/ 日本語。設定画面で「システム / 日本語 / English」を選択。初期値は端末ロケール（未対応言語は英語） |
| 設定画面 | 言語、既定アスペクト比、既定タイマー、タイムラプス間隔、シャッター音、バックグラウンド音声、バージョン、開発者サイト等へのリンク |
| UI | 固定ダークテーマ。エッジトゥエッジ（safeDrawing インセット）。縦画面は縦積み、横画面・幅 600dp 以上は右サイドの縦レール。キャプチャボタンに contentDescription |

## 3. 既知の制約（v2.1.0 時点で継続）

- バックグラウンド録画はプロセス生存が前提（画面オフ・アプリバックグラウンドは可）。タスク除去・プロセス終了で停止。完全デタッチの無制限録画は対象外。
- スローモーション / パノラマは OTHERS に UI エントリのみ。実処理は未実装（将来枠）。High-Speed Capture Session / OpenCV スティッチングが必要。
- 論理マルチカメラの背後に隠れた物理サブカメラは個別選択できない場合がある。
- 実機カメラ挙動の QA は未実施。コンパイル・単体テスト（Robolectric）・lint・署名検証のみで判断。
- シャッター音は MediaActionSound の再生有無のみ制御（Android の仕様上、細かな音量制御・強制音の抑止は不可）。
